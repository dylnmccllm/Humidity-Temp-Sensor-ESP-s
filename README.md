# Humidity-Temp-Sensor-ESP-s

The reciever collects data from the MQTT broker and displays information onto an oled screen using the given library.
The ESP will also sent email alerts if any number is out of safe parameters.
Make sure to add ssd1306.py and umail.py to this ESP so that it can run the libraries.
You will also need to make a gmail account (or other smtp server account if you change some of the code) and get an app password for the ESP
